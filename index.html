2. The Agent: Multi-Sub-Agent Architecture (`agent.py`)

What was built, how sub-agents interact, and where human intervention was needed.

Human Needed: 0% (Fully Autonomous)

5 Specialized Sub-Agents Built

1. OrchestratorAgent (Planner & Task Router)

Deconstructs the 100 target apps, manages pipeline execution flow, and dispatches sub-agent tasks.

2. DiscoverySubAgent (Composio Web / Firecrawl)

Scrapes developer hubs, auth documentation, and OpenAPI/Swagger JSON specs via Composio SDK.

3. SchemaExtractorAgent (Instructor / Pydantic / GPT-4o)

Enforces structured JSON model extraction for auth methods, gating status, and MCP buildability.

4. HeadlessVerifierAgent (Playwright Chromium / browser-use)

Probes live /signup portals to detect sales demo walls vs instant signups.

5. EvaluatorAgent (Self-Correction Loop)

Cross-references raw doc claims against browser assertions, overrides errors, and outputs the delta.

3. Verification & Accuracy Delta (Pass 1 vs. Pass 2)

Automated accuracy check on a 50-app sample comparing LLM extraction against Playwright DOM probes.

+18.0% Accuracy Delta
Why 46/50 Test Cases Passed After Pass 2 (92.0% Accuracy)

In Pass 1, raw LLM document extraction achieved 74.0% accuracy (37/50 correct). Raw documentation text frequently mentions developer endpoints, leading the LLM to misidentify enterprise-gated platforms (like DealCloud, Google Ads, and Marketo) as free self-serve tools.

In Pass 2, the HeadlessVerifierAgent launched a Playwright Chromium browser to probe live /signup portals for exact DOM signals ("Request a Demo", "Contact Sales", "Review Queue"). This automatically detected and corrected 9 enterprise false positives without human intervention, boosting accuracy to 92.0% (46/50 passed).

• 9 Automated Corrections Applied: Google Ads, ServiceNow, Marketo, LinkedIn Ads, WhatsApp Business, Amazon SP-API, ZoomInfo, Brex, Runway ML
• 4 Remaining Mismatches (Edge Cases): Magento (open-source vs cloud licensing), Octoparse (regional API availability), Kayako (docs discrepancy), Wrike (plan-tier gating)
