3. Root Cause: Why 4/50 Failed in Pass 2

DOM inspection resolved 9 enterprise false positives, but missed 4 structural edge cases:

1. Deep In-App Paywalls
Ahrefs, SE Ranking

Free user signup worked, but key generation was locked inside a paid settings sub-tab.

2. Review / Token Queues
Google Ads, Meta Ads

Sandbox keys generated instantly, but live calls require manual offline compliance review.

3. CLI / Local Binaries
Sherlock, Mermaid CLI

Open-source binaries lacking a hosted web signup; initially misclassified as "Missing API".

4. Hidden Multi-Headers
Copper CRM, Harvest

Required custom tenant headers (Harvest-Account-Id) alongside standard bearer tokens.
